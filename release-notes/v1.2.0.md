## FreeMind 1.2.0

### 备注支持 Markdown
- 备注框换成所见即所得的 Markdown 编辑器：边输入边显示标题、粗体、斜体、列表、引用、链接
- 支持 `==高亮==` 和 `~~删除线~~`
- 代码块按语言着色：在 ``` 后写上语言名即可，比如 ```swift
- 支持数学公式：行内写 `$E=mc^2$`，独占一行写 `$$ … $$`
- 打开备注弹窗后光标直接在输入框里，可以马上输入
- 原有备注不受影响，文件里保存的仍然是 Markdown 文本

## FreeMind 1.2.0

### Markdown in notes
- The note box is now a live Markdown editor: headings, bold, italic, lists, quotes and links are shown as you type
- Supports `==highlight==` and `~~strikethrough~~`
- Code blocks are colored by language: put the language name after the opening ```, for example ```swift
- Math formulas: write `$E=mc^2$` inline, or put `$$ … $$` on its own lines for a block
- The cursor is in the note box as soon as the note popover opens, so you can start typing right away
- Existing notes are unaffected; files still store the note as Markdown text
