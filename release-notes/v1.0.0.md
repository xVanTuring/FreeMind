## FreeMind 1.0.0

FreeMind 的第一个正式版本：macOS 原生的思维导图应用，操作方式参照 XMind，键盘就能完成大部分编辑。需要 macOS 14 或更高版本。

### 画导图
- 五种结构：思维导图、逻辑图（向右 / 向左）、组织结构图、树状图，随时切换
- 12 套内置风格，背景、分支配色、字体、线宽都能调整，再存成自定义风格
- 备注、超链接、附件、主题图片、标签、标记、外框、联系线
- Tab 加子主题、Return 加同级主题，选中后直接打字就能改文字，支持中文输入法
- ⌘F 查找主题文字、标签和备注

### 文件
- `.fmind` 包格式，附件直接存在文件里；折叠状态、缩放比例和位置随文件保存
- 导入 Markdown、OPML、XMind（新版和 XMind 8）、纯文本缩进大纲
- 导出 Markdown、OPML、PNG、PDF，以及打印
- Finder 里可以看到 `.fmind` 的缩略图，按空格预览

### 其他
- 欢迎窗口列出最近打开的导图；新建时可以从模板库选模板
- 自动保存、版本浏览、撤销 / 重做、窗口标签页、深色模式
- 本机 MCP 服务，Claude Code 等 AI Agent 可以读取和编辑打开的导图（设置 ▸ Agent）
- 自动检查更新（FreeMind ▸ 检查更新…）
- 中英文界面，跟随系统语言

### 安装
下载 `FreeMind-1.0.0.dmg`，打开后把 FreeMind 拖进“应用程序”。App 已用 Developer ID 签名并经过 Apple 公证。

## FreeMind 1.0.0

The first release of FreeMind, a native macOS mind-mapping app modeled on XMind, built so that most editing can be done from the keyboard. Requires macOS 14 or later.

### Mapping
- Five structures: mind map, logic chart (right / left), org chart and tree chart, switchable at any time
- 12 built-in themes; adjust background, branch colors, fonts and line widths, then save your own
- Notes, hyperlinks, attachments, topic images, labels, markers, boundaries and relationships
- Tab adds a child, Return adds a sibling, and typing on a selected topic edits it (input methods supported)
- ⌘F searches topic text, labels and notes

### Files
- `.fmind` package format with attachments stored inside; fold state, zoom and scroll position are saved with the file
- Import Markdown, OPML, XMind (current and XMind 8) and indented plain-text outlines
- Export Markdown, OPML, PNG and PDF, or print
- Finder thumbnails and Quick Look previews for `.fmind` files

### More
- Welcome window with recent maps; pick a template when creating a new map
- Autosave, version browsing, undo / redo, window tabs and dark mode
- Local MCP server so AI agents such as Claude Code can read and edit open maps (Settings ▸ Agent)
- Automatic update checks (FreeMind ▸ Check for Updates…)
- English and Chinese interface, following the system language

### Install
Download `FreeMind-1.0.0.dmg`, open it and drag FreeMind into Applications. The app is signed with Developer ID and notarized by Apple.
